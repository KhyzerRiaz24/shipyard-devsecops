## Suggested description

Built and tested a containerised release journal using React, Express and MongoDB, with authenticated writes, health checks, metrics, backup restoration and documented failure exercises. Added GitHub Actions checks and a free interactive showcase. The repository also includes Terraform, Kubernetes, Argo CD, Jenkins and monitoring configuration for a future AWS deployment.

The public showcase uses browser-local demo records. The real API/database application runs through Docker Compose; the public site is not a live AWS or Kubernetes deployment.

## Suggested post

I've published Shipyard, a DevSecOps portfolio project built to make the delivery process easy to explain.

The project includes a tested React/Express/MongoDB application, Docker containers, authenticated API writes, health checks, metrics and backup/recovery runbooks. GitHub Actions checks the code before publishing the free interactive demo.

I also documented the Terraform, Kubernetes, GitOps and Jenkins setup, including the tradeoffs and what still needs a live AWS environment to verify.
